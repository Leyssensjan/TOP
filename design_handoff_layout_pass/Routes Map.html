Routes, on the actual map

Real OpenStreetMap tiles, darkened to sit inside the app's ink palette, with the route drawn over them in amber. Tap a route to switch; pinch and drag to look around. Start and finish are marked at Berouw.

Five loops built from the run you described — Doornzelestraat out, then whichever bridge you feel like: Bataviabrug, Matadibrug, Verapazbrug, or all the way to the Muidebrug. Amber dots mark the bridges; laps multiply the distance, which is how you said you stretch a run.

Quay legs are snapped to the OpenStreetMap footpath network (OSRM). Where the router's data predates a dock bridge it tries to detour kilometres around it, so any leg that routes more than 2.6× its straight-line length is drawn direct instead — which means the kilometre figures are close but conservative until you run one with GPS and the recorded track replaces it.

This screen is plain HTML with Leaflet, so it drops into the Next app as a client component with the same markup. OSM's public tile server rate-limits sandboxed previews, so an occasional grey "access blocked" tile here is the preview, not the code — from your own Vercel domain the tiles load normally.
